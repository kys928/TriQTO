# Prospective FIT-only correlation-shrinkage calibration pilot

**Recorded before run, 2026-10-25; explicitly exploratory and data-informed.** Following FIT five-fold source-calibration and predictive-region analysis, joint 6D chi-square coverage was about 91–92% against a nominal 95%. This is not a normality proof. Aim: determine whether noisy off-diagonal covariance, rather than inadequate marginal scale, contributes to this deficiency.

Use the same 120 original FIT circuit families only, first root/candidate/observation, 16 repeated acquisitions at N/2N/4N, and predeclared bootstrap reference indices {0,7,15}. FIT folds defined by existing family SHA256 assignment. Each observed-count bootstrap uses one real count table and 192 N-shot simulations, and the global two coordinate/matched covariance factors are estimated from the four **training** family folds only.

For each shot budget and held-out FIT family fold, choose **one correlation-shrinkage parameter** `beta` from the frozen grid {0,0.25,0.5,0.75,1}, using the **mean per-family Gaussian pseudo-negative-log-likelihood** of held-out acquisition residuals **within the four training family folds only**. Covariance transformation: `Sigma_beta=(1-beta)Sigma_calibrated+beta diag(diag(Sigma_calibrated))`, where the diagonal retains feature-wise variance, PSD is preserved, and all off-diagonal correlations (including coordinate/matched cross terms) are damped. The variance of the observed-reference minus the mean of the other 15 draws is approximately `(16/15)*Sigma_beta`. To handle numerical degeneracy, use a frozen `1e-8 * trace(Sigma_beta)/6` diagonal ridge (with absolute floor `1e-12`) before inversion. Report if excessive ridge is needed.

**Primary diagnostic:** held-out FIT fold mean per-family Gaussian pseudo-NLL of beta-tuned versus beta=0. **Secondary:** full 6D 95% chi-square region coverage, coordinate/matched 3D coverages and Frobenius error vs empirical covariance; count of cases when beta=1 destroys all off-diagonal information. All families included, no filter or hindsight grid changes. Fit-only statistical estimates remain exploratory; the 95% chi-square reference is a diagnostic because true feature law may not be normal.

No oracle probabilities, SELECTION/TEST/label truth, original 36 diagnostics, frozen model inference, R1/R2 feature attenuation, reserved source data, QPU or additional calibration shots. Do not select R2 after this run; an externally disjoint family cohort remains mandatory for confirmation and any source-dependence claims.
